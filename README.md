# HR Management System

A web-based Human Resource Management System developed using Python and Django. This project aims to simplify HR operations by providing a centralized platform for managing employee information and organizational workflows.

## 🚀 Project Overview

The HR Management System is designed to help organizations organize and manage their human resource activities efficiently. It provides a web-based interface for handling HR-related information and workflows.

- Centralized HR Management

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/abinfrancis-03/hr_management_CS-Project.git
```

### 2. Navigate to the Project Folder

```bash
cd hr_management_CS-Project
```

### 3. Create a Virtual Environment

```bash
python -m venv env
```

### 4. Activate the Virtual Environment

**Windows:**
```bash
env\Scripts\activate
```

**Linux / macOS:**
```bash
source env/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Database Migrations

```bash
python manage.py migrate
```

### 7. Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

http://127.0.0.1:8000/
